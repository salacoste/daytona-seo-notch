# Font licenses

Fonts are not bundled with the UI kit package; each consumer ships its own
WOFF2 files plus license texts (kit policy:
`packages/ui-kit/styles/fonts.example.css`).

| Font | License | Canonical text |
|---|---|---|
| Cygre (Book / Regular / SemiBold / ExtraBold) | Commercial EULA | [Cygre-EULA.pdf](https://github.com/salacoste/spacechemical-ui-kit) — see `apps/demo/src/assets/fonts/licenses/Cygre-EULA.pdf` in the ui-kit repo. Verify rights before reuse outside Space Chemical projects. |
| NT Somic (Variable) | SIL OFL 1.1 | [NT-Somic-OFL-1.1.txt](https://github.com/salacoste/spacechemical-ui-kit) — `apps/demo/src/assets/fonts/licenses/NT-Somic-OFL-1.1.txt`; canonical: <https://openfontlicense.org/open-font-license-official-text/> |
| Inter (Variable) | SIL OFL 1.1 | [Inter-OFL-1.1.txt](https://github.com/salacoste/spacechemical-ui-kit) — `apps/demo/src/assets/fonts/licenses/Inter-OFL-1.1.txt`; canonical: <https://github.com/rsms/inter/blob/main/LICENSE.txt> |

Both OFL fonts are redistributed with their license texts available at the
links above. Cygre is used here under the Space Chemical project license; see
the ui-kit repository for the EULA.
