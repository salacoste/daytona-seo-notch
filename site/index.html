How it works

Skills orchestrate an executable runtime

Agent Skills (SKILL.md) that Antigravity reads natively — every skill becomes a slash command; every finding comes from a script that fetched, rendered or measured it.

Layer 1

Antigravity-native skills

9-skill SEO line (daytona-seo-notch*) + a 22-skill marketing suite, zero Claude Code bindings: no plugin roots, no subagent idioms, no hooks.

Layer 2

Executable runtime

60 Python scripts under uv — render, crawl, parse, PSI/CrUX, sitemap discovery, schema generation, drift engine, agentic checks. Plus 66 zero-dependency Node CLIs.

Layer 3

Free-first data

Rendering, robots/sitemap, Common Crawl and keyless PSI/CrUX by default. Paid providers (DataForSEO, Ahrefs, AIsa) are opt-in through Antigravity's MCP config.

FAQ

Common questions

Does this work with Claude Code, Cursor or Codex?
The skills follow the open Agent Skills format (SKILL.md), so any tool that reads .agents/skills/ can use them. The runtime needs uv with Python 3.11+, the data CLIs need Node 18+. This repo is tuned for Google Antigravity: native slash-command discovery, task-planned audit tracks and MCP config.
How is it different from claude-seo?
Same executable DNA — 60 Python scripts, MIT, fully attributed — with every Claude Code binding removed: no CLAUDE_PLUGIN_ROOT, no subagents or hooks, a uv-managed runtime inside the repo, plus the merged AI-visibility domain and the marketing suite from marketingskills.
Is the SEO audit data really free?
Yes. The default audit path runs on free sources: headless rendering, robots.txt and sitemap analysis, Common Crawl domain metrics, and PageSpeed/CrUX where keyless access allows. A free GOOGLE_API_KEY unlocks field Core Web Vitals; paid providers like DataForSEO or Ahrefs are strictly opt-in via MCP or CLIs.
Is it safe to run against client sites?
The audit is read-only and respects robots.txt. The only active probe (a WAF user-agent matrix) is explicitly gated behind owner authorization. API keys stay in a local 0600 .env.marketing file that CI verifies is never committed.
